# 📊 Calculadora de IMC

Projeto simples de uma **Calculadora de IMC (Índice de Massa Corporal)** desenvolvido com **HTML, CSS e JavaScript**.

Este projeto foi criado com o objetivo de praticar estruturação de páginas, estilização com CSS e manipulação do DOM com JavaScript.

---

## 🚀 Demonstração

🔗 Acesse o projeto online:  
👉 https://giovannacostaxavier.github.io/projeto-IMC/

---

## 📌 Funcionalidades

- Inserção de **peso (kg)**
- Inserção de **altura (m)**
- Cálculo automático do **IMC**
- Exibição do resultado na tela
- Interface simples e intuitiva

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

---

## 📂 Estrutura do Projeto

- `index.html` – Estrutura da página  
- `style.css` – Estilização da interface  
- `script.js` – Lógica do cálculo e manipulação do DOM  

---

## ▶ Como executar localmente

1. Baixe ou clone o repositório  
2. Abra o projeto no **VS Code**  
3. Clique com o botão direito no arquivo `index.html`  
4. Selecione **"Open with Live Server"**  

Ou simplesmente abra o arquivo `index.html` no navegador.
